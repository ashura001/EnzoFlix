À quoi sert notre projet ?

Intégration API OMDb

Connexion directe à l'API OMDb (Open Movie Database) pour récupérer en temps réel les données de milliers de films via des requêtes HTTP asynchrones.

📂 Structure du Projet sous Visual Studio Code

Pour développer ce projet proprement, l'espace de travail sous Visual Studio Code est structuré autour d'un dossier racine regroupant le code source et les assets :

📁 Corps de notre projet EnzoFlix/
↳ 📄 index.html # Structure HTML & Logique SPA des 3 pages
↳ 🎨 style.css # Styles globaux, thèmes sombres & grille CSS
↳ 📜 script.js # Gestion des événements et appels fetch() à l'API OMDb
